# LoveLive! 今日恋みくじ

移动端优先的静态粉丝互动页。左右滑动六企划官方封面，点击播放团歌，长按票根 0.5 秒后经过 GSAP 舞台换场抽出一位学园偶像。

## 本地运行

双击 `start_local_server.bat`，或在项目目录运行：

```bash
python -m http.server 5173
```

打开 `http://localhost:5173`。

## 当前体验

- 六张官方企划封面一一对应，可滑动、点击索引切换或点击封面播放团歌。
- 单一 GSAP 时间线负责蓄力、海报扫动、票根揭晓和反向返回。
- 结果页以黑白金的御神签幕揭晓角色与完整签文；63 位角色均使用独立应援色与脸部构图，随机抽卡仍限定为约定的 14 人。
- 全员图鉴只显示在主页；顶部 `MEMBERS` 在首页和结果页都可直达。切换企划时，角色先聚拢，再逐张归位。
- 声音默认关闭；抽签不会自动播放，用户主动点击播放后才加载音频。
- 支持指针取消、键盘长按与 `prefers-reduced-motion`。

## 验证

```bash
node tests/validate-data.cjs
```

UI 自动检查使用本机 Edge 与 Playwright，脚本位于 `tests/ui-check.cjs`。
