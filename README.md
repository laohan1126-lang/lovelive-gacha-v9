# LoveLive! 今日幸运扭蛋机

一个可离线运行的静态网页项目：输入 CN / 昵称，点击 **“拉拉人不灭！”**，抽出今天与你相遇的 LoveLive! 学园偶像签。

## 直接运行

### 方式 A：直接打开

双击 `index.html` 即可打开。封面、头像、角色图鉴、抽签结果和复制签文都能使用。

### 方式 B：本地服务器运行（推荐，音频更稳定）

Windows 用户双击：

```bat
start_local_server.bat
```

或者在项目文件夹运行：

```bash
python -m http.server 5173
```

然后打开浏览器访问：

```text
http://localhost:5173
```

## 资源替换

项目没有内置受版权保护的图片和音乐。你可以把自己拥有使用权、或仅在个人/线下活动中合法使用的素材放入这些目录：

```text
assets/cover/      六代合照封面
assets/avatars/    角色头像
assets/audio/      代表曲音频 mp3
```

封面文件名固定：

```text
muse.jpg
aqours.jpg
nijigasaki.jpg
liella.jpg
hasunosora.jpg
bluebird.jpg
```

头像和音频文件名见 `assets/avatars/README.md` 与 `assets/audio/README.md`。

## 本版内容

- 六代封面拼图区域：μ’s / Aqours / 虹咲 / Liella! / 莲之空 / BLUEBIRD。
- CN 输入与本地记忆。
- 抽签按钮文案：拉拉人不灭！
- 全员图鉴：按企划分组。
- 63 位角色数据卡。
- 角色卡字段：中文名、日文名、罗马字、CV、属性概括、代表歌曲、角色介绍、大吉理由、小知识。
- 结果卡视觉：按企划代表色和角色应援色自动换色。
- 代表曲播放按钮：本地 mp3 存在时播放，不存在时只提示缺文件。
- 复制今日签文。

## 数据边界

本项目是粉丝向互动页面原型，不是官方数据库。角色名单、CV 和企划归属参考公开资料整理；BLUEBIRD 与莲之空 105 期属于较新的内容，正式公开活动前建议再按官方页面复核一次。

## 可继续升级

- 加入竖版签文海报导出。
- 加入“今日只抽一次”的本地记录模式。
- 加入多皮肤：粉色应援棒 / 黑金神社 / 街机扭蛋机。
- 将数据拆成可视化 JSON 编辑器，方便你后续手动修正角色文案。
